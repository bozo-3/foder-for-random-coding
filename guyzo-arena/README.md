# GUYZO: Neon Uprising

A standalone browser lane-battler. Open `index.html` in a modern browser to play; no build step or external assets are needed.

## How to play
- Press **DEPLOY** to start.
- Click a Guyzo card, then click one of the three lanes. Units move and fight automatically.
- Energy regenerates over time. Scout is fast, Tank is durable, Sniper has long range, and Medic heals allies.
- Destroy the hostile core before it destroys yours. Press **P** or the pause button to pause.

All game logic and graphics are in `index.html`.
