# GUYZO: Neon Uprising

A standalone browser lane-battler. Open `index.html` in a browser to play; no build step is needed.

## Play
1. Press **DEPLOY** to start the match.
2. Select a card, then click/tap a battlefield lane to deploy a unit.
3. Energy regenerates. Send units down lanes to destroy the enemy core.
4. Press **P** or the pause button to pause.

The game is self-contained in `index.html`.
